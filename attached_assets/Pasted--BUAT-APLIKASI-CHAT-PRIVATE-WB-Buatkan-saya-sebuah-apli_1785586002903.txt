# BUAT APLIKASI CHAT PRIVATE "WB"

Buatkan saya sebuah aplikasi chat pribadi bernama **WB**.

WB adalah sebuah **website PWA (Progressive Web App)** yang memiliki pengalaman seperti aplikasi WhatsApp.

Aplikasi ini bukan aplikasi native Android/iOS.

Aplikasi harus:

* Bisa dibuka melalui browser
* Bisa digunakan di HP Android
* Bisa digunakan di iPhone
* Bisa digunakan di tablet
* Bisa digunakan di desktop
* Bisa di-install ke Home Screen seperti aplikasi
* Bisa berjalan fullscreen seperti aplikasi

---
